## この章でやること

午前・前半パートで手動作成した Azure インフラを、Copilot Chat と Azure Resources 拡張機能を使って読み解きます。最後に Mermaid 記法で構成図を作成します。

目安時間: 25分

## 手順

### Azure Resources 拡張機能から実リソースを確認

1. Azure Resources 拡張機能を開きます。
1. 対象のサブスクリプション、リソースグループを選択します。手順中のサンプル名は、自分のチームのリソース名に読み替えてください。
1. Virtual Network、Subnet、Virtual Machine、Network Security Group、NAT Gateway、Bastion を確認します。
1. 確認したリソース名をメモします。リソース名、種類、所属するサブネット、Public IP の有無、NSG の関連付けが分かる程度で十分です。

Azure サブスクリプションへのアクセス権がない場合は、講師の画面共有を見ながら同じ情報をメモします。

### Copilot Chat で構成を整理

1. Copilot Chat を Ask に切り替えます。この章では、まだファイルを編集させません。
1. Copilot Chat に、メモしたリソース一覧を貼り付けます。メモをファイルに保存した場合は、`#file` などの候補からそのファイルを参照します。
1. ワークスペース全体を調べる候補が `#` の一覧に表示される場合は、それを使い、どのファイルを根拠に回答したかも尋ねます。
1. リソース同士の関係を整理してもらいます。
    - この Azure リソース一覧を、ネットワーク、コンピュート、セキュリティ、運用の観点で分類してください。
    - VNet、Subnet、VM、NSG、NAT Gateway、Bastion の関係を説明してください。
    - インターネットからアクセスできる経路と、閉域内だけの経路を分けて説明してください。
1. 回答を読み、手動で作ったリソースの役割を確認します。

### Mermaid 構成図の作成

1. PDFの構成図や画面キャプチャを利用できる場合は、画像をチャットに添付し、画像から読み取れる要素を先に列挙してもらいます。機密情報が写っていないことを確認してから添付してください。
1. Copilot Chat に Mermaid 図の作成を依頼します。
    - 次の Azure リソース一覧をもとに、Mermaid の構成図を作成してください。
    - VNet、Subnet、VM、Bastion、NAT Gateway、Public IP、NSG の関係が分かるようにしてください。
    - 管理者の接続経路とアウトバウンド通信の経路を分けて表現してください。
1. 回答された Mermaid 図を新しい Markdown ファイルに貼り付けます。
1. Visual Studio Code の Markdown Preview、Mermaid 対応拡張機能、または Mermaid Live Editor で表示を確認します。

## プロンプト例

- この構成の単一障害点になりそうな箇所はどこですか？
- GitLab VM に Public IP が付いている場合のメリット・デメリットを説明してください。
- NAT Gateway と Public IP の役割の違いを初心者向けに説明してください。
- NSG の設定をレビューするときに確認すべきポイントをチェックリスト化してください。
- この構成を本番環境に近づけるなら、どのような改善が考えられますか？
- この Mermaid 図を、説明用にもっとシンプルにしてください。

## 余裕がある方向けの追加ワーク

1. Mermaid 図を「詳細版」と「説明用の簡略版」の2種類に分けて作ります。
1. Copilot に図のレビューを依頼し、分かりにくい点や不足しているリソースを指摘してもらいます。
1. チーム内で Mermaid 図を見比べ、プロンプトの違いで図の粒度がどう変わるかを共有します。
